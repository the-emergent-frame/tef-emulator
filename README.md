# TEF Emulator

An experimental, event-driven emulator for exploring spacetime rollout and emergent phenomena in **The Emergent Frame**.

**Status:** runnable CPU reference, experiment 0001. A persistent source extends independent causal channels; a separate observer maps that history into schematic intrinsic-untwisted or radial observer phase spines. This is a candidate rule laboratory, with matter formation and physical energy transfer still open.

## Run the observer

Requires **Rust 1.75+** with Cargo and **Python 3.10+**. The reference has no third-party runtime dependencies, package installation, or remote assets.

```sh
git clone git@github.com:the-emergent-frame/tef-emulator.git
cd tef-emulator
python3 python/serve.py
```

Open **http://127.0.0.1:8765**. Startup builds the Rust engine offline. The server listens on loopback only; stop it with Ctrl+C. Use `--port 8766` if needed.

The English interface supports source birth and event replay, orbit/zoom, Intrinsic Untwisted and Radial Observer mappings, causal views, balanced or seeded scheduling, phase and depth diagnostics, and JSON import/export. A run is generated by Rust before playback begins. Animation speed changes only the observer.

## Reproduce a run

```sh
python3 python/run.py --scheduler seeded --seed 42 --output runs/seeded.json
python3 python/run.py --verify runs/seeded.json
python3 python/compare.py
```

Exports include the rule, configuration, full causal history, final summary, Git revision, engine source and binary hashes, and wall-clock provenance metadata. Repeated seeds reproduce the history; provenance timestamps differ. The independent Python verifier checks local transitions and accounting, not authenticity or the scheduler's seed claim.

The [experiment specification](experiments/0001-single-source-rollout/README.md) and [exact transition rule](rules/source-channels-v0.1/README.md) define what is being simulated. The default uses 256 channels and 32,768 local updates. The current bounds are 2,048 channels and 200,000 updates per run.

## Architecture

- **Rust:** local state transitions, causal parent records, deterministic scheduling and replay.
- **Python:** batched subprocess interface, experiment artifacts, verification and local HTTP server.
- **JavaScript / Canvas:** a read-only intrinsic relational adapter, disposable observer mappings, and Canvas projection / causal inspection.

The initial data structure is a source with independent chains, stored in vectors. PyO3/maturin, general graph storage, and Rerun remain later integration options. The current bridge avoids per-event Python calls and keeps the engine independent of the viewer.

```text
crates/tef-core/  Reference engine and tef-run CLI
python/          Experiment API, analysis, verifier, local server
rules/           Versioned candidate rules and assumptions
experiments/     Experiment definitions and reference observations
viewer/public/   English browser observer
docs/           Architecture and research methodology
```

See the [architecture](docs/architecture.md) and [contribution guide](CONTRIBUTING.md).

## Checks

```sh
cargo fmt --all -- --check
cargo test --workspace --offline
cargo clippy --workspace --all-targets --offline -- -D warnings
PYTHONPATH=python python3 -m unittest discover -s python/tests -v
node --check viewer/public/app.js
node --test viewer/tests/*.test.mjs
```

Node is only needed for JavaScript syntax and observer tests. Tests cover local state consumption, transfer accounting, independent-event commutation, deterministic histories, phase cycles, artifact round trips, and rejection of corrupted transitions.

## Research context

[The Emergent Frame](https://theemergentframe.org) maintains the research context. The [research releases](https://github.com/the-emergent-frame/research-releases) contain archived paper sources and numerical checks.

[Paper VIII v3.12](https://doi.org/10.5281/zenodo.22776137) motivates the current
intrinsic-untwisted representation through a conditional transported-complex
construction. Experiment 0001 does not implement K_perp or validate its
volume-growth theorem.

3D isotropy in the radial observer, channel independence, and local phase advance are explicit inputs here. Transport weight is dimensionless, with no assigned GeV conversion. Neither a large energy scale nor a large event count establishes quantum behavior. A result establishes a consequence of its specified rules; connecting it to physical phenomena requires further evidence.
